# Image Upload Directory for Pobreng Maestra

Place your image files directly into this directory:

1. **Logo**: `public/images/logo.png`
   - Transparent PNG recommended.
   - Hot pink "Pobreng Maestra" typography logo.

2. **Hero / Cover Banner**: `public/images/hero-banner.png`
   - Aspect ratio: 16:9 or Facebook Cover (approx 1920x600 to 1920x1080).
   - Yellow sky with coconut palms, bahay kubo, and avatar.

3. **Avatar / Portrait**: `public/images/avatar.png`
   - Square or transparent portrait of Maestra Cecille smiling with glasses.

4. **Thumbnails**: `public/images/thumbnails/`
   - `thumb-bicol-express.jpg`
   - `thumb-sorsogon-tour.jpg`
   - `thumb-pagcopra.jpg`
   - `thumb-ginataan.jpg`
   - `thumb-mayon-resort.jpg`
   - `thumb-streetfood.jpg`

> **Note:** The code has built-in graceful fallbacks (`onError` handlers and SVG fallbacks). As soon as you place real images with these filenames into `public/images/`, the website will immediately display them!
