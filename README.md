# Pobreng Maestra — Official Influencer & Media Kit Website

**Creator:** Cecille Escullar ("Pobreng Maestra")  
**Niche:** Bicol & Philippine Travel, Food Vlogging, Provincial Life & Culture  
**Audience:** 1.4M+ Facebook Followers | 25M+ Monthly Impressions  
**Framework:** React 19 + Vite + Tailwind CSS v4  
**GitHub Repository:** [gwaps04/pobreng-maestra](https://github.com/gwaps04/pobreng-maestra.git)

---

## 🎨 Brand Design & Color Scheme

- **Base Canvas:** Soft cream / off-white (`#FAF7F2`) — clean, airy, minimalistic.
- **Accent Highlighting:** Sunny bright yellow (`#FEDE2B` / `#FACC15`) — header underlines, badge highlights, and section breaks reflecting the warm tropical Bicol sunshine.
- **Logo & Signature Pop:** Vibrant hot pink (`#E81C76`) — matching the official Pobreng Maestra logo bubble branding and commercial action triggers.
- **Grounding Tone:** Tropical deep green (`#14532D`) — menu active states, badges, and grounded footer reflecting Bicol's coconut groves and lush landscapes.

---

## 🧭 Navigation Structure (Fixed Layout)

1. **Home:** High-impact hero cover, creator narrative, vital metrics overview, and quick partner CTAs.
2. **Meet the Maestra:** Her personal journey as an educator, Bicolana storyteller, core values, and family-safe content promise.
3. **Audience Stats:** Verified analytics (1.4M+ followers, 25M+ monthly reach, 12.4% engagement rate, geographic and demographic purchasing power breakdown).
4. **Brand Partnerships:** 4 commercial packages (Resort Features, Restaurant Spotlight, Product Integration, Ambassadorship) + Video portfolio thumbnail showcases.
5. **Let's Collaborate:** Dedicated B2B partnership proposal inquiry form, official contact channels (`escullarcecille3@gmail.com`), and brand FAQs.

## 📁 Image Asset Uploads (`public/images/`)

You can easily customize and drop your images into `public/images/`:

- `public/images/logo.png` — Hot pink Pobreng Maestra logo
- `public/images/hero-banner.png` — Facebook cover / hero landscape banner
- `public/images/avatar.png` — Cecille's caricature or portrait
- `public/images/thumbnails/` — Video campaign thumbnail previews

> *Note: Built-in SVG fallbacks and `onError` handlers prevent any broken image boxes if files are not yet uploaded.*

## 🚀 Running the Project

```bash
# Install dependencies

# Build for production
npm run build
```
